# tender-watch — поиск тендеров по ключевым словам

Ищет лоты на площадках Узбекистана по трём профилям:

| Профиль | Для чего | Примеры ключей |
|---|---|---|
| `owl-studio` | Owl Studio | разработка сайта, веб-портал, мобильное приложение, `veb-sayt`, `mobil ilova` |
| `medusa` | Медуза | клининг, уборка, мойка автотранспорта, `tozalash`, `avtomobil yuvish` |
| `goods-china` | закуп товара из Китая | футболки, спецодежда, текстиль, мебель, оргтехника, `futbolka`, `ish kiyim` |

Ищет **по основам слов и на трёх языках** (русский, узбекская латиница, английский),
потому что площадки Узбекистана публикуют лоты вперемешку. То есть `уборк` ловит
«уборка / уборки / уборочные», а `мойк+автотранспорт` — и «мойка автотранспорта»,
и «услуги по мойке автотранспорта служебного автопарка».

Зависимостей нет — нужен только Python 3.8+.

## Быстрый старт

```bash
cd tools/tender-watch
python3 tender_watch.py --site all --pages 3
```

Результат — два файла в `out/`:

* `tenders.md` — отчёт таблицей, сгруппированный по компаниям
* `tenders.csv` — то же для Excel (открывается без танцев с кодировкой)

В обоих: балл релевантности, название лота, заказчик, сумма, срок подачи,
какое именно ключевое слово сработало, и прямая ссылка на лот.

## Три режима

**1. Онлайн — сам качает страницы**

```bash
python3 tender_watch.py --site tzone --site etender --pages 5
python3 tender_watch.py --site all --profile medusa      # только по одной компании
```

Площадки: `tzone`, `tenderzone`, `etender`, `xarid`, `exarid`, `tenderweek`,
`goszakupka`, `bicotender`, либо `all`.

**2. Офлайн — разбирает сохранённые страницы** (обходит любую авторизацию)

Открываете нужную страницу в браузере, `Ctrl+S` → «Веб-страница, только HTML», потом:

```bash
python3 tender_watch.py --html-file "~/Downloads/*.html" --base-url https://trade.tzone.uz/
```

`--base-url` нужен, чтобы ссылки на лоты в отчёте были кликабельными.

**3. Закрытые площадки — через ваши cookies, без передачи пароля**

Ставите в браузер расширение экспорта cookies (например, «Get cookies.txt LOCALLY»),
сохраняете `cookies.txt` для нужного домена и:

```bash
python3 tender_watch.py --site tzone --cookies-file cookies.txt --pages 5
```

Пароль при этом никуда не уходит и никому не передаётся. **Логин и пароль
не нужно присылать в переписку** — для работы достаточно cookies или
сохранённых HTML-страниц.

Если площадка рисует список через JavaScript и обычная загрузка отдаёт пустую
страницу — добавьте `--render` (нужен установленный Playwright).

## Как настроить под себя

Все ключевые слова лежат в `keywords.json` — правится без программирования.

* `strong` — вес 3, точное попадание в профиль
* `broad` — вес 1, широкое слово (само по себе шумит, но в сумме помогает)
* `+` — все части должны встретиться в одном лоте, в любом порядке

Лот попадает в отчёт при сумме баллов ≥ 3. Планку меняет `--min-score`:
`--min-score 6` оставит только самые точные попадания, `--min-score 1`
покажет вообще всё, что хоть как-то похоже.

Добавить своё направление — просто новый блок в `keywords.json`:

```json
"my-profile": {
  "title": "Название для отчёта",
  "strong": ["ключ1", "ключ2+ключ3"],
  "broad": ["широкий-ключ"]
}
```

## Регулярный мониторинг

Лоты появляются и закрываются каждый день, поэтому смысл есть в расписании.
Раз в сутки в 8 утра:

```bash
crontab -e
# 0 8 * * *  cd /path/to/tools/tender-watch && python3 tender_watch.py --site all --pages 5
```

## Важное про условия участия

Отчёт даёт срок подачи, сумму и заказчика — этого хватает, чтобы отсеять лишнее.
**Полные условия всегда смотрите на самой странице лота** по ссылке из отчёта:
там гарантийный взнос, требования к участнику, техзадание и спецификация.
Для закупки товара из Китая критично именно ТЗ — сертификаты соответствия,
маркировка и сроки поставки обычно не выполняются «с колёс», их надо проверять
до подачи заявки.
