# Очередь тем для будущих вопросов

> Сюда падают темы, которые ещё не закрыты, и вопросы, на которые я не ответил.
> Отсюда берутся вопросы на следующий день. Закрытые — удалять.

## Про жизнь
- [ ] Имя, город, часовой пояс
- [ ] Чем зарабатывает сейчас (работа / учёба / фриланс)
- [ ] Реальный распорядок дня и сколько часов есть на проекты
- [ ] Цели: на год / 3 месяца / неделю
- [ ] Что чаще всего срывает планы
- [ ] Кто вокруг: работает один или есть команда/партнёры
- [ ] Как относится к деньгам в проектах: хобби или должно кормить
- [ ] Что было последним доведённым до конца делом и почему получилось

## Про проекты
- [ ] Полный список проектов, включая идеи
- [ ] Что за сайт в этом репозитории и для кого
- [ ] Критерий «готово» для главного проекта
- [ ] Главный блокер прямо сейчас
- [ ] Есть ли пользователи / клиенты, говорил ли с ними
- [ ] Технический стек, который знает и которым хочет владеть
- [ ] Где хостит / деплоит
- [ ] Какие проекты были брошены и почему

## Про общение со мной
- [ ] Предпочитаемая длина ответа
- [ ] Списки или сплошной текст
- [ ] Нужны ли объяснения «почему» или сразу «как»
- [ ] Что бесит в ответах ИИ
- [ ] Спорить прямо или мягко
- [ ] Действовать без спроса или спрашивать (правки, коммиты)
- [ ] Нужен ли код целиком или только изменённые куски
- [ ] Эмодзи — да или нет
