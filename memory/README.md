# Память обо мне — как это работает

Это «мозг» Claude обо мне. Каждая новая сессия Claude начинается с нуля и
помнит только то, что записано здесь. Поэтому всё важное живёт в файлах,
а не в чате.

## Файлы

| Файл | Что там |
|---|---|
| `PROFILE.md` | Я как человек: жизнь, ритм, цели, ценности, контекст |
| `PROJECTS.md` | Мои проекты: суть, стадия, зачем, кому, что мешает |
| `COMMUNICATION.md` | **Как со мной говорить**: формат, длина, тон, что нравится / бесит |
| `OPEN_QUESTIONS.md` | Что ещё неизвестно — очередь тем для будущих вопросов |
| `daily/ГГГГ-ММ-ДД.md` | Вопросы дня + мои ответы |

## Ежедневный цикл

1. **Каждый день** приходит сессия с 10 вопросами. Состав по умолчанию:
   - 3 вопроса — про жизнь (состояние, ритм, что происходит)
   - 4 вопроса — про проекты (что делаю, зачем, для кого, что мешает, шаг дальше)
   - 3 вопроса — про то, как Claude должен отвечать (формат, тон, что понравилось)
2. Вопросы сразу записываются в `daily/ГГГГ-ММ-ДД.md`.
3. Я отвечаю — можно коротко, можно на часть вопросов, можно одним абзацем.
4. Claude записывает ответы туда же **и разносит выводы** по
   `PROFILE.md` / `PROJECTS.md` / `COMMUNICATION.md`.
5. Всё коммитится и пушится в ветку `claude/daily-life-projects-questions-cmbn1p`.

## Правила для вопросов

- Вопросы **не повторяются**. Перед составлением — прочитать последние
  7 файлов в `daily/` и `OPEN_QUESTIONS.md`.
- Вопросы **конкретные**, а не «как дела». Плохо: «как проект?».
  Хорошо: «что именно мешает выкатить лендинг на этой неделе?».
- Вопросы опираются на то, что уже известно: «в прошлый раз ты сказал X —
  получилось?».
- Можно отвечать не на все 10. Пропущенные уходят обратно в `OPEN_QUESTIONS.md`.
- Если я долго не отвечаю — вопросы не копятся лавиной, старые
  неотвеченные просто переезжают в `OPEN_QUESTIONS.md`.

## Как поменять расписание

Ежедневный запуск сделан через Routine (scheduled trigger).
Скажи Claude: «поменяй время ежедневных вопросов на HH:MM» — он вызовет
`update_trigger`. Остановить: «выключи ежедневные вопросы».
